# ai-sandbox

A step-by-step guide to preparing a sandbox for AI agents using [nono](https://nono.sh) and [Pi](https://pi.dev). nono controls filesystem and network access; Pi runs the coding workflow inside the sandbox using one dedicated profile.

## Setup guides

1. [nono](docs/nono.md) — install the sandbox and create the `pi` profile.
2. [Pi](docs/pi.md) — install the latest Pi, configure PATH, and check it runs inside nono.

Commands target Linux Bash, including WSL 2. Provider login and permissions for a full coding session will be configured next.
